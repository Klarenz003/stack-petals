# Approved chibi pose concept

`chibi-poses-approved.png` was generated using the built-in image tool and
approved by the user before game integration. The 1536 × 1024 image has an alpha
channel. It is used unchanged through SVG crop wrappers, not converted to paths.

Prompt summary: match the original Stack Petals chibi boy/girl identities,
detailed pixel shading, outfits and flower clip; show bouquet/laptop/letter
holding, front/rear diagonal walking and paired idle poses; transparent
background, no panels, labels or scene; 6 columns × 4 rows.

This is a pose concept, not a complete animation atlas. Two touching row
boundaries were measured per cell rather than relying on connected components.
Original artwork and the prior code-native SVG actors are retained unchanged.

## Milo laptop movement concept

`milo-laptop-poses.png` is a 1024 x 1536 transparent PNG generated by the built-in
image tool, then approved for use. Prompt: match approved Milo's brown hair,
black hoodie and white sneakers; carry an open grey laptop; four columns of
walking/running variations across eight directional rows; alpha background,
no labels, UI, pets or girl. It is displayed through SVG clipping, not traced.

The output has touching rows and imperfect paired strides. Crops follow measured
per-column alpha boundaries. Rear-right mirrors the actual rear-left row; the
generated supposed rear-right row is a profile and is not used. The bottom row
is cut off by the image edge and is not used. Walking uses the clearest stride
variation in columns 1 and 3; running uses columns 3 and 4 plus movement bob.
Existing idle artwork is retained. This is not a complete authored gait cycle.
